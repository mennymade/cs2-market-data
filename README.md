# CS2 Unbox Legends - Live Market Price CDN

Automated multi-market pricing engine for **CS2 Unbox Legends**.
Updated daily at 00:00 UTC via GitHub Actions.

## API Endpoint
- **Latest Prices JSON:** `https://raw.githubusercontent.com/mennymade/cs2-market-data/main/prices_v1.json`

- CSFloat
